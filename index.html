Unit-I: Overview of Operating Systems

Short Question Lists

Q1. What is an operating system?

Ans: An operating system is system software that manages computer hardware, software resources, and provides services to programs.

Q2. Give one difference between a process and a thread.

Ans: Processes have separate memory space, while threads share memory within the same process.

Q3. What is a Process Control Block (PCB)?

Ans: A data structure containing process information like process ID, state, and CPU registers.

Q4. What is a system call?

Ans: A system call is a programmatic way to request services from the operating system.

Unit-II: Process Management

Short Question Lists

Q1. What is process scheduling?

Ans: Process scheduling is the method by which the operating system decides the order in which processes access the CPU.

Q2. What is a semaphore?

Ans: A semaphore is a synchronization tool used to control access to shared resources.

Q3. What is a binary semaphore?

Ans: A semaphore that takes only 0 or 1 as values.

Q4. What is the main purpose of semaphores?

Ans: To avoid race conditions and ensure process synchronization.

Q5. What is a deadlock?

Ans: Deadlock is a situation where processes wait indefinitely for resources held by each other.

Unit-III: Memory Management

One-Mark Questions

Q1. What is memory management?

Ans: It is the OS function that handles allocation and deallocation of memory to processes.

Q2. What is cache memory?

Ans: A small, fast memory unit near the CPU that stores frequently used data.

Q3. What is a logical address?

Ans: An address generated by the CPU during program execution, also called a virtual address.

Q4. What is a physical address?

Ans: The actual location of data in memory hardware.

Q5. What is paging?

Ans: A memory management technique that loads fixed-size pages of a process into main memory.

Q6. What is segmentation?

Ans: A memory management technique that divides a process into variable-sized logical segments.

Q7. What does a segment table store?

Ans: Base address and length (limit) of each segment.

Unit-IV: File System and Disk Scheduling

One-Mark Questions

Q1. What is a file system?

Ans: A method used by the OS to organize and manage files on a storage device.

Q2. What is disk scheduling?

Ans: An algorithm that manages the order of I/O requests to the disk to optimize access.

Q3. What is seek time?

Ans: The time taken by the disk head to move to the desired track.

Q4. What is SSTF?

Ans: Shortest Seek Time First — services the request closest to the current head position.

Q5. What does C-SCAN stand for?

Ans: Circular-SCAN.

Q6. What is the main difference between LOOK and C-LOOK?

Ans: LOOK reverses direction and serves requests on the way back, while C-LOOK jumps to the smallest request without serving on return.

Unit-V: I/O Management

One-Mark Questions with Answers

Q1. What does DMA stand for?

Ans: Direct Memory Access.

Q2. Which software controls a specific I/O device?

Ans: Device driver.

Q3. Name one example of a software interrupt.

Ans: A system call (or divide-by-zero trap).

Q4. Which I/O technique keeps checking the device status again and again?

Ans: Polling (programmed I/O).

Q5. Which instructions are used in port-mapped I/O?

Ans: IN and OUT.

Q6. In which multiprocessing type do all processors have equal roles?

Ans: Symmetric Multiprocessing (SMP).
